# git cheat sheet
## Commands 
- `git init` - initializes an empty git repository. 
- `git status` - it shows which changes have been staged and which are not. Which are not being tracked by git
- `git diff` - it shows exactly which lines you changed.
- `git add` - to pick what changes you want to include in your commit. You can pick files or directories with commands: git add filename, git add . 
- `git commit -m ".."` - captures a snapshot of the project's currently staged changes. you can go back to them later. git commit is only local
- `git push` - uploads your local branch commits to a remote
- `git log` - lists commits' history
